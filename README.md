# StudyQuest 英検準1級 📚⚔️

专为 **英検準1級** 做的 iPhone 学习 App：每天用碎片时间刷单词，每周写作文让 AI 按英検标准批改。

- 目标：**2026年度第3回 一次試験（本会場）**，默认日期 **2027/1/24**（报名前请到英検官网确认，设置里可以改）
- 一次试验的三个技能（阅读・写作・听力）各占 1/3 分数，**写作单项就占 1/3**
- 最弱的是**词汇** → 单词卡＋大問1 形式的 4 选 1 练习是核心

## 📲 下载/安装方法（iPhone）

这是一个 **PWA（网页 App）**：用 Safari 打开网址，“添加到主屏幕”后，就和普通 App 一样有图标、全屏运行、离线可用。
不需要 App Store、不需要 Mac、不花钱。（上架 App Store 需要 Mac + 每年 99 美元的开发者账号，来不及也不划算。）

### 第 1 步：把 App 放到网上（只做一次，用电脑或手机浏览器都行）

**方法 A：GitHub Pages（推荐，免费）**

免费账号的 GitHub Pages 只支持 **公开（Public）仓库**。仓库里只有 App 代码，**你的 API Key 和学习数据只保存在手机上，不会进仓库**，公开没有问题。

1. 打开 https://github.com/Poly233/Study-app → **Settings**
2. 最下面 **Danger Zone → Change repository visibility → Public**
3. 左侧菜单 **Pages** → *Build and deployment* → Source 选 **Deploy from a branch**
4. Branch 选 **`claude/iphone-study-app-uocrff`**（或合并后的 `main`），文件夹选 **`/ (root)`** → **Save**
5. 等 1–2 分钟，页面上方会出现网址：**https://poly233.github.io/Study-app/**

**方法 B：不想公开仓库 → Netlify Drop（免费）**

1. 在 GitHub 上切到这个分支 → **Code → Download ZIP**，解压
2. 电脑浏览器打开 https://app.netlify.com/drop ，把解压后的文件夹拖进去
3. 会得到一个 `https://xxxx.netlify.app` 的网址（注册免费账号可以永久保留）

### 第 2 步：装到 iPhone 上

1. 用 **Safari** 打开上面的网址（一定要用 Safari）
2. 点底部的 **分享按钮**（方框+向上箭头）
3. 选 **“添加到主屏幕”** → 添加
4. 从主屏幕的 **StudyQuest** 图标打开 ✅

> 更新：以后代码更新了，联网打开 App 就会自动拿到新版本。

### 第 3 步：设置 AI（推荐）

App 里 **设置 → AI**：

1. 浏览器打开 **console.anthropic.com** 注册
2. **Billing** 充值：**建议先充 10 美元**，用两三天后在 Console 的 **Usage** 看花了多少，不够再补 5–10 美元。建议关掉 Auto-reload（自动续充）

   | 操作（大约，按 1 美元≈150 日元） | Opus 5.5 | Sonnet 5.5 |
   |---|---|---|
   | 单词书 1–2 页 → 单词卡 | 20–40 日元 | 10–20 日元 |
   | 批改一篇作文 | 8–15 日元 | 4–8 日元 |
   | 解析一道过去问错题 | 15–40 日元 | 8–20 日元 |
   | AI 辅导：每轮对话 | 3–6 日元 | 2–3 日元 |
   | 费曼模式：一次（几轮对话＋评分） | 15–30 日元 | 8–15 日元 |

   到考试为止大量使用（单词书 40 页、作文 25 篇、错题 40 道）：Opus 5.5 约 13 美元，Sonnet 5.5 约 7 美元。以上是估算，实际以 Console 的 Usage 为准。单词卡和作文批改也可以在 Claude 聊天里做，那样就不花 API 的钱
3. **API Keys → Create Key**，复制粘贴到 App 里，点“测试”

**不想花钱？** 导入时点 **“🆓 免费：复制提示词”**：App 会给你一段提示词，你在免费的 Claude App（或 ChatGPT）里附上同样的照片发送，再把回复粘贴回来即可。单词卡、错题解析、作文批改都能用这种方式做（只有“AI 辅导聊天”和“出类题”需要 Key）。

## 🎮 功能

| 功能 | 说明 |
|---|---|
| 🔤 **单词卡（3 种练法）** | 新词先**翻卡**记意思；记过的词会轮流出现：**4 选 1 填空**（和大問1 一样的形式）、翻卡、**看意思想英文**。答对越快，下次出现得越晚 |
| 🔊 **发音** | 单词和例句都能点 🔊 朗读（iPhone 自带的语音，不用网络、不花钱）；设置里可以开“自动发音” |
| 📦 **准1级高频词 360 个** | 9 个卡包，例句和 4 选 1 干扰项全部原创：动词 120・名词 80・形容词副词 80・**句动词 80**・长文社会话题 40。拍照 → 📦 导入卡包 |
| 📷 **単熟語EX → 单词卡** | 在书上把不会的词**打勾或划线**，拍照 → 🔤 单词。只做有记号的词，例句和解释全部原创（不照抄书） |
| ✍️ **英作文** | 原创的 **要約** 4 题、**意見論述** 6 题，也能添加过去问的题目。字数统计、计时，按 **内容・構成・語彙・文法（各 4 分）** 批改，给出修改后的范文；范文里的表达可以一键做成闪卡 |
| ✏️ **过去问错题 → 解析** | 拍题目和解答：为什么选这个、其他选项为什么错、根据句在哪里、这类题的解题套路；还能出同题型的新题 |
| 📖 **补课** | 看不懂的语法、长难句、长文，AI 从零讲到懂 |
| 🗣 **费曼模式** | 用自己的话讲给 AI 扮演的“小明”听，找出漏洞 |
| 🎓 **AI 辅导** | 苏格拉底式提问，引导你自己找到根据 |
| 📅 **复习排程** | 间隔重复（遗忘曲线），考前会保证每张卡至少再出现两次；新词自动平均分配 |

**不用 API Key 也能用**：单词卡包由 Claude 在聊天里做好推送；作文可以点“📋 复制题目和作文”，发到 Claude 聊天里批改，或者用“🆓 复制批改提示词”配合 ChatGPT 等免费 App。

## 🗓 作战计划（到 1/24 约 13 周，App 首页会显示当前阶段）

**第 1 阶段（到 12 月上旬）：词汇打底**
- 每天把单词卡清零（每天新词约 15 个，碎片时间就够）
- 単熟語EX 每天看一点，不会的词打勾 → 拍照发给 Claude 或者用 App 做成卡
- 每周写 1 篇作文（要約和意見論述轮流）

**第 2 阶段（12 月上旬 → 1 月上旬）：过去问 + 写作**
- 官网公开的过去问每周做 1 回，错题拍进来分析
- 作文每周 2 篇；把修改后范文里的表达加入闪卡

**第 3 阶段（最后 3 周）：冲刺**
- 用“🔥 考前冲刺”刷弱项单词
- 按考试时间做过去问
- 作文每天 1 篇（要約 15 分钟、意見論述 20 分钟）

> 一次考试过了以后，在设置里把日期改成二次考试（面接）的日期，再加面接练习。

## 🛠 技术说明

- 纯前端 PWA（HTML/CSS/JS，无需编译），数据存在 IndexedDB
- AI：Anthropic 官方 SDK（`vendor/anthropic.js`，打包自 `@anthropic-ai/sdk`），默认模型 Claude Opus 5.5，可在设置里切换 Sonnet 5.5（便宜一半）
- 数式渲染：KaTeX（含 mhchem 化学式），已内置，离线可用
- 本地预览：`python3 -m http.server` 然后打开 http://localhost:8000

```
index.html            入口
css/app.css           样式（自动深色/浅色）
js/app.js             界面、复习流程（单词卡・4 选 1）、英作文、游戏化
js/eiken.js           英作文的原创题目和字数规则
js/ai.js              Claude 调用与提示词
js/srs.js             考试感知的间隔重复算法
js/db.js              IndexedDB 存储与备份
js/util.js            图片压缩、Markdown/数式渲染
sw.js                 离线缓存
vendor/               Anthropic SDK、KaTeX
```

离线缓存是“联网优先”：联网时总是加载最新代码，断网时用缓存。改动较大时可以顺手把 `sw.js` 里的 `VERSION` 改一下，清掉旧缓存。
